# Loomic - Landing Page

A clean, modern, and responsive landing page built as part of The Odin Project curriculum. This project focuses on mastering layout design using semantic HTML and CSS Flexbox.


## Project Overview

**Loomic** is a sleek, single-page landing designed to showcase a modern product or service. The primary goal of this project was to translate a visual design spec into clean, maintainable HTML and CSS without relying on external frameworks or libraries.

### Key Features:
- Built entirely with semantic **HTML5** and custom **CSS3**.
- Structured utilizing **Flexbox** for a clean, aligned layout.
- Clean design with clear Call-to-Action (CTA) sections.

## Built With

* HTML5
* CSS3 (Custom properties, Flexbox layout)
